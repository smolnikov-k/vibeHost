# Project Knowledge — VibeHosting

Навигационный скилл: подсказывает какие reference-файлы читать в зависимости от задачи.

## Когда что читать

- **Любая задача:** начни с `references/project.md` — обзор, стек, env
- **Работа с БД, API, маршрутами:** читай `references/architecture.md`
- **Код, паттерны, стиль:** читай `references/patterns.md`
- **Деплой, сервера, Nginx:** читай `references/deployment.md`

## Правила

- Читай только нужный файл, не все сразу
- После завершения крупной фичи обнови соответствующий reference-файл
- Не дублируй информацию между файлами
