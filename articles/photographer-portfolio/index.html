Вы фотограф. У вас сотни потрясающих снимков на жёстком диске. Но когда потенциальный клиент спрашивает «а можно посмотреть ваши работы?» — вы отправляете ссылку на Instagram или Google Диск. Это непрофессионально. И это стоит вам заказов.

В этой статье мы создадим портфолио с нуля: от выбора фотографий до публикации на своём адресе. Без конструкторов, без абонентской платы, без ограничений.

Зачем фотографу собственный сайт

Instagram — отличная платформа для привлечения аудитории. Но как инструмент продаж и демонстрации портфолио у него есть серьёзные проблемы:

  • Качество изображений. Instagram сжимает фотографии. Тонкие градиенты, детали в тенях, текстуры — всё теряется. На собственном сайте вы контролируете качество полностью.
  • Структура. В Instagram фотографии показываются в хронологическом порядке. Нельзя разделить свадебные съёмки, портреты и репортажи по категориям. На сайте — можно.
  • Поисковая выдача. Когда невеста гуглит «свадебный фотограф Москва», поисковик показывает сайты, не Instagram-аккаунты.
  • Профессиональное впечатление. Ссылка ivan-photo.hostingvibe.ru в переписке с заказчиком выглядит профессиональнее, чем «загляните в мой инстаграм».
  • Контроль. Instagram может изменить алгоритм, скрыть ваши посты, заблокировать аккаунт. Сайт — ваш. Навсегда.
  • Закрытые галереи. Вы можете создать защищённую паролем страницу для конкретного клиента. Отсняли свадьбу → выложили на сайт → отправили клиенту пароль. Он смотрит, выбирает, делится с гостями.
Статистика: фотографы с собственным сайтом получают в среднем в 2 раза больше заказов от новых клиентов, чем те, кто работает только через Instagram. Причина — доверие и доступность в поиске.

Подготовка: выбор и оптимизация фотографий

Перед созданием сайта нужно подготовить фотографии. Это самый важный этап — от него зависит и внешний вид портфолио, и скорость загрузки.

Сколько фотографий нужно

Меньше, чем вы думаете. Идеальное портфолио — это 15-30 лучших работ. Не 500. Не 200. Именно 15-30. Каждая фотография должна быть такого уровня, что вы готовы напечатать её на стене в рамке.

Правило: если сомневаетесь, включать фото или нет — не включайте. Портфолио оценивают по самой слабой работе, а не по самой сильной.

Категории

Разбейте работы по направлениям:

  • Свадебная съёмка — 5-8 фото, показывающих разные моменты
  • Портреты — 5-8 студийных и уличных портретов
  • Репортаж / мероприятия — 5-8 фото
  • Предметная / фуд-фотография — если снимаете

Оптимизация для веба

Фотографии с камеры весят 10-30 МБ каждая. Для сайта это слишком много. Оптимизируйте:

  • Размер: 1920px по длинной стороне — достаточно для отображения на любом экране
  • Формат: JPEG с качеством 80-85% — оптимальный баланс размера и качества
  • Вес: целевой — 200-400 КБ на фото. Если больше — ещё раз сожмите
  • Имена файлов: осмысленные, латиницей: wedding-ceremony-01.jpg, portrait-studio-anna.jpg

Для оптимизации используйте бесплатные инструменты:

  • Squoosh (squoosh.app) — от Google, работает в браузере
  • TinyPNG — пакетная оптимизация
  • Lightroom Export — настройте пресет: 1920px, Quality 82, Sharpen for Screen
Важно: бесплатный план VibeHosting позволяет загрузить до 50 МБ. При оптимизированных фото по 300 КБ это примерно 150 фотографий — более чем достаточно для портфолио. PRO-план даёт 500 МБ.

Структура портфолио

Хороший сайт фотографа — это прежде всего фотографии. Минимум текста, максимум визуала. Вот проверенная структура:

Первый экран: одна сильная фотография

Полноэкранное фото, которое показывает ваш стиль за 1 секунду. Имя фотографа. Специализация. Кнопка «Смотреть работы».

Галерея по категориям

Вкладки или секции: «Свадьбы», «Портреты», «Репортаж». Клиент сразу находит то, что ему нужно.

Обо мне

3-5 предложений. Опыт, стиль, подход. Одно фото — ваше, с камерой. Клиент хочет видеть человека, которому доверяет съёмку.

Услуги и цены

Необязательно указывать точные цены. Можно написать пакеты: «от 15 000 ₽ за 2 часа». Или «цены по запросу» — но тогда добавьте форму связи.

Контакты и форма

Имя, телефон, email, мессенджеры. Форма «Оставить заявку» — имя, email, тип съёмки, предпочтительная дата.

5JavaScript: фильтрация и lightbox

Добавьте перед закрывающим </body>:

<script>
// Фильтрация по категориям
document.querySelectorAll('.category-nav a').forEach(link => {
    link.addEventListener('click', (e) => {
        e.preventDefault();
        const filter = link.dataset.filter;

        // Активная вкладка
        document.querySelectorAll('.category-nav a')
            .forEach(l => l.classList.remove('active'));
        link.classList.add('active');

        // Показ/скрытие фото
        document.querySelectorAll('.gallery img')
            .forEach(img => {
                if (filter === 'all'
                    || img.dataset.category === filter) {
                    img.style.display = 'block';
                } else {
                    img.style.display = 'none';
                }
            });
    });
});

// Lightbox
const lightbox = document.getElementById('lightbox');
const lightboxImg = lightbox.querySelector('img');

document.querySelectorAll('.gallery img').forEach(img => {
    img.addEventListener('click', () => {
        lightboxImg.src = img.src;
        lightboxImg.alt = img.alt;
        lightbox.classList.add('active');
    });
});

lightbox.addEventListener('click', () => {
    lightbox.classList.remove('active');
});
</script>

Теперь посетитель может фильтровать работы по категориям и открывать фотографии на полный экран.

CSS-галерея: masonry-раскладка

Вы заметили, что в CSS используется свойство columns. Это создаёт masonry-раскладку (как на Pinterest) — фотографии разного формата красиво заполняют пространство без пустых мест.

Как это работает:

.gallery {
    columns: 3;       /* 3 колонки */
    column-gap: 8px;  /* отступ между колонками */
}

.gallery img {
    width: 100%;
    margin-bottom: 8px;
}

Браузер автоматически распределяет фотографии по колонкам, учитывая их высоту. Горизонтальные, вертикальные, квадратные — все встают красиво. На мобильных колонок становится меньше через @media-запросы.

Lightbox без библиотек

Мы добавили простой lightbox на чистом JavaScript — без jQuery, без сторонних библиотек. Клик по фото → оно открывается на полный экран на тёмном фоне. Клик в любое место → закрывается. Это минимальная, но достаточная реализация.

Если хотите более продвинутый lightbox (пролистывание стрелками, зум), можно подключить библиотеку GLightbox или Fancybox — они весят 5-10 КБ и легко интегрируются.

Одна из самых полезных функций VibeHosting для фотографов — парольная защита. Вот как её использовать:

Сценарий: отправка свадебных фотографий

  1. Вы отсняли свадьбу Маши и Пети.
  2. Обработали 300 фотографий.
  3. Создали отдельную HTML-страницу с галереей — только свадебные фото.
  4. Загрузили на VibeHosting как отдельный сайт: masha-petya-wedding.hostingvibe.ru.
  5. В настройках включили парольную защиту. Пароль: love2026.
  6. Отправили ссылку и пароль Маше и Пете.

Что получают клиенты:

  • Красивую галерею, доступную с любого устройства
  • Возможность показать фото родственникам, поделившись ссылкой и паролем
  • Никаких Google-дисков, никаких «запросить доступ», никаких тяжёлых архивов
Совет: для каждой съёмки создавайте отдельный сайт на VibeHosting. На PRO-плане доступно 3 сайта одновременно — хватит для текущих проектов. Завершённые проекты можно архивировать, освобождая слоты.

Сценарий: закрытое портфолио для конкретного клиента

Крупный клиент (бренд, агентство) хочет видеть ваши работы, но вы не хотите показывать всё публично. Создайте закрытое портфолио:

  • Подборка работ, релевантных запросу клиента
  • Парольная защита
  • Ссылка и пароль — только для этого клиента

Alt-тексты для фотографий

Каждому <img> — осмысленный alt:

  • Плохо: alt="фото 1"
  • Хорошо: alt="Свадебная фотография — первый танец молодожёнов в ресторане"

Это помогает поисковикам понять содержание фотографий и показывать ваш сайт в Google Images и Яндекс.Картинках.

Локальные ключевые слова

Включите в текст город и район: «фотограф в Москве», «свадебная съёмка Подмосковье», «фотосессия в центре». Не перегружайте — естественное упоминание 3-5 раз на странице достаточно.

Скорость загрузки

Оптимизированные фотографии — ключевой фактор. Google ранжирует быстрые сайты выше. Если ваши фото оптимизированы до 200-400 КБ, сайт будет загружаться за 2-3 секунды даже на мобильном интернете.
