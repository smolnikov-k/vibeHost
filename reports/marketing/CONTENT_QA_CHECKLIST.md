# Контент QA чеклист (перед публикацией)

## Текст и полезность
- [ ] Заголовок обещает то, что раскрыто в тексте; нет кликбейта.
- [ ] Первый экран даёт пользу/шаги/результат за <10 секунд чтения.
- [ ] Нет воды: убраны повторяющиеся фразы, «маркетинговый шум».
- [ ] Чёткий CTA (1–2 максимум), релевантен контексту.

## Факты и точность
- [ ] Проверены цены (PRO = 386 ₽), лимиты (FREE 1 сайт/50 МБ), сроки.
- [ ] Инструкции соответствуют текущему UI (скрины/пути меню актуальны).
- [ ] Ссылки ведут на существующие страницы (проверены 200 OK).

## Язык и тон
- [ ] Русский, дружелюбно, без нажима, без capslock/красного спама.
- [ ] Избегаем «скидок навсегда» и пустых обещаний.
- [ ] Нет пассивной агрессии в ре-активации/отмене.

## Структура и формат
- [ ] Есть подзаголовки, списки, визуальные акценты (цитаты/блоки).
- [ ] Изображения/коды подписаны, alt заполнен.
- [ ] Метаданные: title/description/OG/twitter заданы (для блога/страниц).

## Доступность и производительность
- [ ] Размер изображений <= требуемого (webp/png, оптимизировано).
- [ ] Цветовой контраст достаточный, ссылки подчеркнуты или явно кликабельны.
- [ ] Видео/гиф — с превью или весом до разумного лимита.

## Юридическое и конфиденциальность
- [ ] Нет раскрытия персональных данных пользователей/клиентов без разрешения.
- [ ] Не вставляем секреты (ключи, URL с токенами) в текст/коды.

## Финальная проверка
- [ ] Прочитано вслух: звучит естественно и кратко.
- [ ] Проверен рендер на мобильном и десктопе.
- [ ] CTA ведёт на правильный шаг воронки.
